# BuickPlay 0.2.21-buick.2 正式版（code73）

2026-11-01，以 code72 当前工作区收尾，固定 kaiyue。个人后装 FF-5000 车机适配，并非别克原厂车机软件。本次只发布本地安装包，不推送代码或 GitHub Release。

## 本轮主要变化

- 无线连接阶段和耗时展示、完整连接诊断与持久会话归档，支持手机浏览器下载 ZIP；保留手动网络采集。
- 修正残留投屏页面与手动断开后的恢复行为，5分钟未连接后停止自动重试，需手动发起；改善蓝牙恢复唤醒和地址族成功偏好。
- 首次等待 iPhone TCP 从30秒缩短为20秒；TCP到达后的握手及首帧等待仍各自保留30秒，不缩短已建立会话。
- 主界面聚焦无线连接，简化等待页右侧信息，去掉连接主页的新版本提示。
- 车辆小灯变化联动 CarPlay 日夜模式；CarPlay/高德随灯光切换已获实车确认。
- 左下角单行24小时制时钟始终显示，可调字号，日间黑字、夜间白字；使用认证后 iPhone 时间并异步校准系统。
- 增强音频、网络、时间异常与会话诊断。尚未证明解决所有音频卡顿，后续继续验收。

## 安装与配置

正式包名 com.shihab.diplay，名称 BuickPlay，无 debug 后缀。覆盖车机 code46，使用相同正式签名，保留正式版应用数据和热点配置。调试版是独立包，保留其数据并停止运行；调试版设置不会自动覆盖正式版。

板载 MFi 实验入口当前仅对调试版开放，正式版保留原有认证配置，不默认切换实验认证。

## 时间策略

不再调查原厂系统时间不准的根因，也不修改固件、MCU、GPS或启动流程。CarPlay连接后收到 iPhone DeviceTimeUpdate 即使用手机时间；偏差较大时调用受限系统校时接口。连接前暂用系统时间。code72实车已收到通知且差约0.5秒，较大偏差下的root写入留作下一版验收。
