# code97：车灯未知按日间处理，重新构建及code78对比

## 相对code96新增

- 跟随车灯：只有明确小灯开启才用夜间；关闭或未知均按日间。即使当前23点且处于旧定时时段，未知状态也不会自动变暗。
- 移除车灯模式的定时时段兜底和对应定时轮询。定时切换仍按用户设置的时段工作。
- 应用AUTO外观在没有宿主结果且采用车灯模式时默认日间；设置页只在定时模式显示开始/结束时间。
- 九种语言提示同步说明“未知按日间”；相关控制器、应用外观和设置测试同步更新。

上述差异由与code96构建前源码哈希清单对比、当前源码及测试核对确认。code96文档中的“车灯未知按时间兜底”仅描述旧版，本版已经改为日间。
