# BuickPlay 0.2.21-buick.3 后续优化

基线：本地正式版0.2.21-buick.2/code73；暂不切换上游或开始新功能。若未来升级上游版本，按分支规则重新命名；versionCode持续递增。

## 优先验收与优化

1. 连接稳定性与速度：停车场景统计冷启动、热重连、长时间离开后恢复、20秒TCP超时和IPv4/IPv6成功偏好；只有证据支持再改超时/回退。
2. 音频：定位音乐偶发卡顿、起播等待和音画同步；区分无线收包、音轨缓冲、调速与无线ADB采集影响。导航播报和连续播放分别验收。
3. iPhone校时：重启后有偏差时验证自动系统校准结果和重连后的时钟；仅采用CarPlay手机时间。停止调查车机RTC、GPS、MCU等原厂时间根因，不列为后续任务。
4. ACC/深度休眠：停车上机验证唤醒、热点恢复、连接恢复与长期资源占用。
5. 板载MFi：实验能力保持调试版范围，汇总另一模型的测试证据，再决定是否进入正式版。不得把本地证书验签等同于iPhone完整接受。
6. 页面整合与音量：连接管理/投屏任务进一步整合；原厂全局音量条和步长仍按实车能力评估，不宣称当前已统一原厂系统条。
7. 日志：完整去返程、重启、多日保留和手机ZIP下载的长期验收；排查测试中一次下载服务404/401不一致，单项及完整复测均已通过，暂未复现。

## 边界

不增加健康摘要，不增加iPhone电量/充电状态；当前只优化无线CarPlay。车辆小灯联动已通过，环境光选项已移除。后续功能另行实现，本次code73只收尾。
