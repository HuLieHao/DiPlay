# 主动断开后的页面清理

用户已确认：本次修复残留 CarPlay 页面、意外重连和重复管理页；单卡片整合延期，不推送远程。

## 设计与实施

- 保留目前独立的管理任务和 CarPlay 任务。返回管理页使用 NEW_TASK、CLEAR_TOP、SINGLE_TOP，复用管理任务。
- 主动断开先使自动连接请求失效，再关闭会话和 CarPlay 任务；管理页保留。
- 恢复旧页面、权限回调和画面尺寸回调均不得绕过手动停止状态；显式连接允许新的尝试。
- 用回归测试覆盖停止后页面恢复、返回导航、任务选择和再次连接，再运行仓库完整 CI。
- 手机/车机验收：连接 → 返回管理 → 断开 → 最近任务只剩管理页；再连接成功；正常返回不影响会话；异常掉线仍自动恢复。
