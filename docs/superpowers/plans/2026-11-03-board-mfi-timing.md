# 板载 MFi 读取时序修正

用户已选择按此前方案优化板载认证；本轮在当前 kaiyue/code78 基础准备 code79，保留其他未提交改动，不操作车机、不推送。

## 设计

仅 FF_5000/FF-5000 且 I2C 后端、/dev/i2c-2 使用 MFi 寄存器传输装饰器：单字节寄存器选择成功后等待5ms，再允许后续读取。扫描、证书、签名状态/结果、错误码读取全部经同一个传输对象。保留STOP分开的原始事务语义。其他机型/总线、CH341、软件/远程认证不增加等待。

等待可中断，恢复中断标志并终止，不能继续读设备。保留现有有限重试，不改变手机握手期限。补充只含总线/地址/寄存器/阶段/长度/次数/耗时/errno的诊断，禁止输出挑战、签名或证书正文。不改变原厂服务和权限、不增加认证自动回退或缓存。
